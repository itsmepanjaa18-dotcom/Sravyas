SRAVYA BIRTHDAY WEBSITE
========================
Open index.html in a browser to preview the site.

To personalize:
1. Replace memory1.jpg ... memory4.jpg with your own photos (keep the filenames).
2. Edit the text in index.html if you want different wording.
3. The countdown is set to September 5, 2026 (India time).
4. For the "Our Song" section, add an audio player and an audio file you have permission to use.

To publish:
- Upload the folder to a static hosting service such as Netlify, GitHub Pages, or Cloudflare Pages.
- Then share the generated public link.
